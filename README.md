# Procal Links Limited

Premium real-estate website for **Procal Links Limited** — a Ghanaian agency helping clients buy, rent, sell and invest. Based at 69 Lagos Ave, Ghana.

This is a client version of the Amek Platinum master template. The original Amek project is unchanged.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Demo content

All listings, testimonials, blog posts and images live in `/data`. Replace those files to swap in live Procal inventory without touching layout components.
